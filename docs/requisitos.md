# Entre Hilos App

## 1. Descripción del proyecto

Entre Hilos App es una aplicación web Full Stack orientada a la gestión y personalización de accesorios elaborados mediante diferentes técnicas de tejido.

La plataforma busca digitalizar la experiencia de compra de la marca Entre Hilos, permitiendo a los clientes conocer los productos disponibles, explorar diseños, solicitar accesorios personalizados y recibir recomendaciones mediante Inteligencia Artificial.

## 2. Problema que resuelve

Los emprendimientos artesanales suelen tener dificultades para mostrar sus productos de manera organizada, gestionar solicitudes personalizadas y ofrecer una experiencia digital que permita al cliente participar en el proceso creativo.

Entre Hilos App busca solucionar esta necesidad mediante una plataforma que conecte la creatividad del cliente con la elaboración artesanal del emprendimiento.

## 3. Usuarios del sistema

### Cliente

Podrá:

- Explorar el catálogo de accesorios.
- Visualizar productos disponibles.
- Solicitar diseños personalizados.
- Recibir recomendaciones mediante IA.
- Contactar con el emprendimiento.

### Administrador

Podrá:

- Iniciar sesión.
- Gestionar productos.
- Administrar solicitudes personalizadas.
- Actualizar información del catálogo.

## 4. Objetivo general

Desarrollar una aplicación web Full Stack para la gestión y personalización de accesorios de Entre Hilos, integrando herramientas modernas de desarrollo e Inteligencia Artificial para mejorar la experiencia del usuario.

## 5. Enfoque del proyecto

La aplicación estará enfocada en la personalización de accesorios y no únicamente en la venta tradicional de productos.

La propuesta de valor será permitir que cada cliente participe en la creación de un accesorio con significado.
